# Module 9 Assessment 1 – Image Gallery Plus

A responsive image gallery website built with **HTML5**, **Bootstrap 5**, and custom CSS.

## Overview
This project includes:
- A dark Bootstrap navigation bar
- A Bootstrap image carousel with captions
- Team/member profile cards
- Three featured content sections with images
- Footer with utility links

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript (Bootstrap bundle)
- jQuery (included in project)

## Project Structure
```text
image gallary plus/
├── css/
│   ├── bootstrap.min.css
│   └── custom.css
├── js/
│   ├── jquery-4.0.0.min.js
│   └── bootstrap.bundle.min.js
├── images/
├── index.html
└── README.md
```

## How to Run
1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open `index.html` in your browser  
   (or use VS Code Live Server).
